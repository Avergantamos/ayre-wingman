# Ayre: instant phrases

Say these exactly for an instant keypress with no thinking delay. Anything else, say it
naturally ("throw some flares", "give me more shields") and she works it out in a second or two.

- **Next attacker**: Next Attacker
- **Next hostile**: Next Hostile
- **Flares**: Launch Flares
- **Noise / Chaff**: Launch Noise
- **Dump flares**: Dump Flares
- **Engage quantum / Punch it**: Engage Quantum Drive
- **SCM mode / Combat mode**: SCM Mode
- **Missile mode**: Missile Mode
- **Power off / Main power off**: Main Power Off
- **Shields off**: Shields Off
- **Thrusters off / Cut thrusters**: Thrusters Off
- **Scan mode**: Scan Mode
- **Ping**: Ping
- **Gear down**: Gear Down
- **Gear up**: Gear Up
- **Request landing / Call the tower / Open the hangar / Hail ATC / Hail the ATC / Call ATC / Get me a hangar / Request a hangar / Get us a hangar / Get a hangar / I need a hangar / Find me a hangar / Request hangar / Hangar please / Get me a landing pad / Get me a pad**: Request Landing
- **Lights on / Lamp on**: Lights On
- **Lights off / Lamp off**: Lights Off
- **Open the doors**: Open and Unlock All Doors
- **Close the doors / Lock it down**: Close and Lock All Doors
